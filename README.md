# 90-Day AI Engineer Challenge

A 90-day hands-on learning challenge focused on becoming job-ready for entry-level **AI/ML Engineering** roles.

The goal is simple:

**Learn one core concept each day → apply it through 3 small projects → keep reusing older skills → finish with a production-style AI capstone.**

## How It Works

Each day focuses on **one main concept**.

- **Project 1:** Easy introduction
- **Project 2:** Practical use case
- **Project 3:** Challenge combining the new concept with older skills

The projects are intentionally small so I can consistently build alongside my Computer Science studies.

## Roadmap

**Days 1–10** — Python Engineering  
**Days 11–20** — SQL & Data Engineering  
**Days 21–35** — Machine Learning  
**Days 36–50** — Deep Learning & PyTorch  
**Days 51–65** — LLMs, Embeddings & RAG  
**Days 66–78** — FastAPI, Docker, Testing, CI/CD & MLOps  
**Days 79–84** — AI Agents & Tool Calling  
**Days 85–90** — Production AI Capstone

## Skills

`Python` `SQL` `Pandas` `NumPy` `scikit-learn` `PyTorch` `FastAPI` `PostgreSQL` `LLMs` `Hugging Face` `Embeddings` `Vector Databases` `RAG` `Docker` `GitHub Actions` `MLOps` `AI Agents`
